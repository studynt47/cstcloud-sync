# cstcloud-sync

[English](./README.md) | 中文

`cstcloud-sync` 是一个 Obsidian 插件，用于和 S3 兼容的对象存储存储桶做**双向同步**。
它面向 [cstcloud.cn](https://cstcloud.cn) 对象存储：服务端点（endpoint）、区域（region）
和 URL 风格均已写死，因此你只需要填写三个字段即可使用。

## 声明

- **本插件不是 Obsidian 官方提供的[同步服务](https://obsidian.md/sync)。**
- **本插件与上游 `remotely-save` 项目无隶属、认证或支持关系**，详见
  [归属与许可](#归属与许可)。

## !!!注意!!!

**请务必、务必在首次使用前备份你的库（Vault）。**

库是数据的源头。第一次跑双向同步之前，请先做一份副本（或依赖你自己的版本管理）。

## 功能

- **仅支持 S3 / S3 兼容对象存储。** 服务类型、服务地址（`s3.cstcloud.cn`）、区域
  （`us-east-1`）与 path style URL 均已硬编码，设置页中不再提供服务选择器。
- **双向同步。** 本地新增、远端修改、删除都会双向传播。同步方向也可收窄为
  仅推送 / 仅拉取 / 仅推送与删除 / 仅拉取与删除。
- **冲突处理。** 当同一个文件在两端都被修改时，按「冲突处理方式」设置保留较新或
  较大的那个文件；「保护修改百分比」还可额外拦截「一次同步会覆盖掉大量刚修改过的
  本地内容」的情况。
- **定时自动同步。** 可按间隔定时同步、启动后同步一次，也可以用侧边栏图标或命令
  面板手动触发。
- **跳过大文件。** 超过阈值的文件不参与同步。
- **最小侵入。** 默认不同步隐藏文件与文件夹（以 `.` 或 `_` 开头）；`_` 开头项、
  Obsidian 配置文件夹、书签文件可分别开启。
- **状态栏。** 可在状态栏显示上一次成功同步的时间。
- **支持移动端。** 支持 Obsidian 移动端（iOS / Android）。

## 限制

- **仅支持 S3 兼容存储。** 本分支不支持 Dropbox、OneDrive、WebDAV、Webdis、
  Google Drive、Box、pCloud、Yandex Disk、Koofr、Azure Blob Storage，相关代码已移除。
- **不提供端到端加密。** 本版本没有加密口令设置项，文件会以明文内容上传到存储桶。
  请不要依赖本插件来保护存储桶中的敏感内容。
- **没有「PRO」功能。** 上游项目的付费功能（智能冲突合并、更多云服务、同步计划管理、
  性能分析面板等）不在本插件范围内。
- **没有二维码导入/导出设置**，也没有内置的调试面板。
- **不上传元数据。** 远端的 `metadata` 文件仅用于把插件自身管理的文件排除在同步之外，
  并不会写入存储桶。

## 安装

本插件尚未发布到 Obsidian 社区插件商店，请手动安装：

1. 下载发布压缩包并解压。
2. 若尚不存在，创建插件目录 `<库>/.obsidian/plugins/cstcloud-sync/`。
3. 把 `main.js`、`manifest.json`、`LICENSE` 复制到该目录。
4. 重启 Obsidian，在 *设置 → 第三方插件* 中启用 `cstcloud-sync`。

## 使用

### 设置项

打开 *设置 → cstcloud-sync*。

**S3 设置（基本）**

| 字段 | 说明 |
|---|---|
| `Access Key ID` | 存储桶的访问密钥 ID。 |
| `Secret Access Key` | 存储桶的访问密钥。 |
| `Bucket` | 用于同步的存储桶名称。 |

点击**检查连接**验证凭证，插件会对存储桶执行 `HeadBucket` 与 `ListObjectsV2` 请求。

访问密钥与密钥会保存在插件本地的 `data.json`（位于库的配置文件夹内）。能读到该文件
的人，也能读到你的存储桶凭证。

**进阶设置**

- `分块并行度` —— 大文件分块上传时的并行分块数。
- `自动运行` —— 每隔 N 分钟自动同步一次。
- `启动后自动运行` —— Obsidian 启动后不久自动同步一次。
- `跳过大文件` —— 忽略大于指定大小的文件。
- `状态栏显示开关` —— 在状态栏显示上一次成功同步的时间。
- `并行度` —— 同时上传 / 下载的文件数。
- `同步 _ 文件或文件夹` —— 同时同步以 `_` 开头的文件与文件夹。
- `同步配置文件夹`（实验性质）—— 同时同步 Obsidian 配置文件夹。
- `同步书签`（实验性质）—— 同时同步 `bookmarks.json`。
- `删除文件到哪里` —— 删除到系统回收站，或 Obsidian 的 `.trash`。
- `冲突处理方式` —— `保留较新` 或 `保留较大`。
- `保护修改百分比` —— 当本次同步会覆盖大量刚修改过的本地内容时中止同步。
- `同步方向` —— `双向`、`仅增量推送`、`仅增量拉取`、`仅增量推送与删除`、
  `仅增量拉取与删除`。

### 命令

- `start-sync` —— 立即开始一次同步。
- `start-sync-dry-run` —— 以演练（dry-run）模式开始同步，不会写入任何数据。

两个命令都可以在命令面板中找到，侧边栏图标触发的是 `start-sync`。

## 调试

- 打开 Obsidian 开发者控制台（*帮助 → 开发者工具*）查看控制台输出。
- 同步计划与上一次同步明细保存在插件的本地数据库中；日志级别固定为 `info`。
